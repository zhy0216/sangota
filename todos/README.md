# todos — 对标《杀戮尖塔》的功能缺口

每个文件一个功能，按「优先级 / 依赖关系」排序。

**完成的任务，文件名加 `-done` 后缀**（`03-card-upgrades.md` →
`03-card-upgrades-done.md`），索引里打 ✅。所以 `ls todos/` 本身就是进度看板。

文件内统一结构：

- **现状** — 当前代码里有什么、在哪一行
- **原版行为** — 《杀戮尖塔》怎么做的
- **设计方案** — 本项目（三国题材）打算怎么做
- **数据结构** — 需要新增/修改的类型
- **实现步骤** — 可直接开工的清单
- **验收标准** — 做完怎么算过
- **依赖** — 必须先做哪个
