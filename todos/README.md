# todos — 对标《杀戮尖塔》的功能缺口

每个文件一个功能，按「优先级 / 依赖关系」排序。

**完成的任务，文件名加 `-done` 后缀**（`03-card-upgrades.md` →
`03-card-upgrades-done.md`），索引里打 ✅。所以 `ls todos/` 本身就是进度看板。

文件内统一结构：

- **现状** — 当前代码里有什么、在哪一行
- **原版行为** — 《杀戮尖塔》怎么做的
- **设计方案** — 本项目（三国题材）打算怎么做
- **数据结构** — 需要新增/修改的类型
- **实现步骤** — 可直接开工的清单
- **验收标准** — 做完怎么算过
- **依赖** — 必须先做哪个

## 第一梯队 · 补完 roguelike 主循环

跑一局完整的塔，目前缺的是「局内成长」和「非战斗房间」。没有这些，
每一局的决策空间只有「选哪张牌」，而原版的深度大半来自遗物 + 升级 + 商店的交叉。

| # | 功能 | 为什么优先 |
|---|---|---|
| [01](01-relics-done.md) ✅ | 遗物系统 | 原版最大的构筑变量，完全缺失 |
| [02](02-potions.md) | 药水系统 | 唯一的「应急资源」，缺了容错极低 |
| [03](03-card-upgrades-done.md) ✅ | 卡牌升级 | 卡池只有 11 张，升级能立刻翻倍深度 |
| [04](04-campfire.md) | 营帐（篝火）选项 | 现在是自动回血，没有决策 |
| [05](05-shop.md) | 商店 | 金币目前只能囤着，没有出口 |
| [06](06-events.md) | 奇遇事件 | 地图 21% 的房间是占位 toast |
